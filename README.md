# Mohamed Asfak - Premium Portfolio

A modern, responsive portfolio website showcasing technical expertise and professional experience.

## 🌟 Features

- **Premium Dark Theme**: Sleek, modern design with carefully crafted color palette
- **Responsive Design**: Fully responsive across all devices and screen sizes

- **Skills Visualization**: Animated progress bars and statistics counters

## 🛠️ Setup Instructions

1. **Clone or Download**: Get the portfolio files
2. **Add Images**: Place your images in the `assets/` folder:
   - `profile.jpg` - Your professional headshot
   - `project1.jpg` - IT Asset Management system screenshot
   - `project2.jpg` - Wallet Management system screenshot
   - `project3.jpg` - E-commerce website screenshot
   - `project4.jpg` - Landing pages screenshot

3. **Customize Content**: Update the HTML with your information:
   - Personal details in the hero section
   - About section content
   - Project descriptions and links
   - Skills and technologies
   - Contact information

4. **Deploy**: Upload to your web hosting service or GitHub Pages

## 📝 Customization Guide

### Personal Information
- Update name, title, and description in `index.html`
- Replace contact details (email, phone, location)
- Add your social media links

### Projects
- Update project titles, descriptions, and technologies
- Add your project URLs to the project links
- Replace project images with your own screenshots

### Skills
- Modify the skills percentages based on your expertise
- Add or remove technology categories
- Update the skills list to match your proficiencies

### Colors and Styling
- Modify CSS variables in `:root` to change the color scheme
- Adjust animations and transitions in the CSS file
- Customize fonts by changing the Google Fonts import
